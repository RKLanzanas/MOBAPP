# Scentiments - E-Commerce Mobile Application

**Scentiments** is a Flutter mobile e-commerce application crafted for luxury perfume shopping.

---

## Features
- **Authentication**: Sign Up, Log In (Username/Password or Google), Account Recovery / Forgot Password (via Gmail verification code or Security Question).
- **Product Catalog**: Curated fragrance showcase with discount tags, categories (Floral, Woody, Fresh, Oriental), and ratings.
- **Search & Sort**: Real-time fragrance search (*Search - De Guzman*) and multi-criteria sorting (Featured, Price Low to High, Price High to Low, Highest Rated, Newest, Discount).
- **Shopping Cart & Checkout**: Add to cart, quantity adjust, promo/discount code input with instant price calculation, free shipping threshold, and checkout flow (*Check out - Burgos/Dael*).
- **Payment Methods**: GCash, Cash on Delivery (COD), and Bank Transfer with input validation.
- **Wishlist & Favorites**: Save favorite perfumes with one-tap management.
- **In-App Messaging / Chats**: Interactive support, scent recommendations, and promotional inquiries.
- **Settings & Profile**: Edit profile details, manage theme (Dark/Light mode switch), and account settings.

---

## Getting Started

### Prerequisites
- [Flutter SDK](https://docs.flutter.dev/get-started/install) (v3.0.0 or higher)
- Android Studio / VS Code with Flutter extension
- Connected Android/iOS Device, Emulator, or Chrome browser

### How to Run
```bash
# 1. Navigate to the Flutter project folder
cd scentiments_perfume

# 2. Get dependencies
flutter pub get

# 3. Launch the app
flutter run
```
